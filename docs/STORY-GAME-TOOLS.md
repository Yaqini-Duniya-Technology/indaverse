# Manuscript and prototype tools

In Story Studio, use **Chapter position** to move a chapter in one step. Set
its writing status and an optional word target, then save to preserve the
order and progress. The manuscript panel groups saved scenes by setting and
shows their character references. Its continuity notes flag common omissions
and duplicate titles so you can jump to the relevant chapter.

Save before downloading HTML or EPUB. Both use the saved chapter order and
include a table of contents. EPUB includes text and chapter headings; project
images and other attachments stay in the workspace.

In Game Studio, open the editor for the saved 2D or 3D blueprint and choose a
starter template. Applying a template replaces the editor draft; save it
before opening the player. The 3D scene editor can place a checkpoint on a
platform and set how many gems are required to finish. Cross the checkpoint
ring to activate it. Falling then returns the player to the checkpoint, while
restarting the test resets checkpoint progress.
