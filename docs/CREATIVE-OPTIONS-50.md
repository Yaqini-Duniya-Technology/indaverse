## Scope and limits

Production tools read the working draft and never write it or save it to the server. Their settings and acceptance checks are temporary. Exports contain planning data; they do not include media files, server history or executable systems. Genre describes design intent. Existing browser prototypes do not implement every listed genre's mechanics.

Browser recovery, validation and version checks from previous batches remain in place. No database migration, secret update, commit or push is part of the installer.
